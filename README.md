# Sweet Crumbled Supply 🍰

Sweet Crumbled Supply is a bakery-themed e-commerce website built with React and Vite. The project lets users explore baking products and interact with a shopping cart through a simple, responsive interface.

## Features

- Browse featured baking products with images, prices, and star ratings
- Add products to the product list
- Increase or decrease product quantities in the shopping cart
- Delete products from the product list
- View the total number of items and automatically calculated cart total

## Technologies

- React
- JavaScript
- HTML
- CSS
- Bootstrap
- Vite

## What I Learned

Through this project, I practiced building reusable React components, managing application state with `useState`, handling user input with forms, and updating displayed information dynamically based on user interactions.

## Running Locally

1. Install [Node.js](https://nodejs.org/).
2. Clone or download this repository.
3. Open a terminal in the project folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal.

## Note

This is a front-end demonstration project. Product and cart changes are held in application state and are not permanently saved, and the site does not process real payments.
